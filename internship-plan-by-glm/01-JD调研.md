## 三、Java 后端实习岗：高频要求

1. Java 基础：集合、并发（线程池/锁）、JVM（90%）
2. Spring 生态：Spring Boot / Spring Cloud / MyBatis（85%）
3. MySQL + Redis：索引/事务/锁、缓存（80%）
4. 数据结构与算法：大厂手撕必考，LeetCode ~200 题覆盖实习难度
5. 分布式/中间件认知：MQ、RPC、负载均衡（50%，大厂常见）
6. 语言弹性：字节/美团/小红书大量岗 Java/Go 二选一

加分项：实习/项目落地经历、中间件源码理解、高并发项目、竞赛/开源/博客。

7. Agent 四大模块：LLM（大脑）、规划、记忆（短期上下文+长期存储）、工具

## 六、结论：什么样的项目能"通吃"两类 JD

> **"纯 Java CRUD 后端"与"纯 Demo 级 Agent"都在贬值；"Java 工程底座 + 生产级 RAG/Agent 能力 + 量化评测"的复合项目**，是唯一能同时命中 Java 后端 JD、Java+AI 复合 JD、大厂 AI 应用工程 JD 的项目形态。

- 核心项目按 Java 后端 JD 打底（Spring Boot 3 + MySQL + Redis + MQ），AI 层用 Spring AI / Spring AI Alibaba / LangChain4j 实现 RAG + Function Calling + 多轮记忆 + 编排。
- **必须有量化评测**：准备"RAG/Agent 优化前后准确率、召回、延迟、成本"四类数字——这是 JD 和面经共同强调的。
- 补一个非 Java 栈的 Agent 引擎项目覆盖 Python/TS 系 Agent 岗，并体现"复杂工具调用"。
- 加分项性价比：开源贡献 > 微调小实验 > 竞赛/论文（后者是顶尖岗门票，非普通实习门槛）。
